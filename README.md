# 🔐 Animated Neon Login

Login form with a neon effect, floating labels, and a button featuring a light tracing its border. Built using pure HTML and CSS.

### 🔗 Access the project online
**https://rodrigo-sam.github.io/login-neon-animado/**

### ✨ Preview
> Implemented effects:
> - Label that floats when the input is clicked
> - Line with an animated gradient (#00dbde -> #0531f7)
> - Background with a pulsing neon glow
> - Button with a light tracing its border + glow on hover

### 🛠️ Technologies
- HTML5
- CSS3 (keyframes, box-shadow, linear-gradient, pseudo-elements)
